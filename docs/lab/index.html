How to interpret the gate
Each case must match its expected decision, stay within its allowed action set and list all required evidence IDs. Critical case failures and unexpected IDs close the gate, even with a 0% pass-rate threshold. Exit 0 means accepted, exit 1 means a valid evaluation was rejected, and exit 2 means invalid input. This browser port accepts standard JSON only and has input size limits.
